MiniQuake

MiniQuake is an unofficial Windows x64 port of the original GLQuake and WinQuake 1.09 engine to MiniLang, preserving Quake behavior, data formats, QuakeC semantics, Protocol 15 networking, rendering, audio, input, demos, and savegames.
