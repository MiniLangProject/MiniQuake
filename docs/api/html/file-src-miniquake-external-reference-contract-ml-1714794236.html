# originalServerInteropNetworkProvenance

function originalServerInteropNetworkProvenance(transport, remoteAddress, expectedAddress, localServerActive, localAuthoritative, demoPlayback)

A completed signon is not sufficient evidence by itself: if a remote UDP connect times out, Quake may continue with its local demo/start path. External interop therefore requires a live UDP peer matching the requested address and rejects local-authoritative, local-server and demo fallbacks.
