# BP-086 — mod and mission-pack runtime compatibility

- Adds a common inspector for `id1`, mission packs and arbitrary `-game` directories.
- Accepts any valid Quake `progs.dat` version 6 and BSP version 29 rather than imposing stock-id1 function or map counts on mods.
- Adds 22 runtime fixtures and real-data validation hooks for installed `rogue` and `hipnotic` directories.
