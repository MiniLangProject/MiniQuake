# Changelog OPT-001CR3R6

- fehlende `then`-Token des R5-Fensterhelfers beseitigt;
- falsche globale Argumentmutation vollständig entfernt;
- Standard-Fenstermodus an der Videoauswahl implementiert;
- `-fullscreen`, `-mode`, `-current`, `-bpp` und `-force` bleiben explizite Fullscreen-Selektoren;
- OPT-001C-Vertragsidentität als eingefrorene Konstanten getrennt;
- map-spezifischen GLQuake-Kompatibilitätszustand beim Renderer-Destroy zurückgesetzt;
- Kartenwechseltest bleibt hartes Gate;
- fester OPT-001B-Performancevergleich bleibt hart, CR2-Inkrementalvergleich wird als Diagnose geführt;
- Inline-, Builder-, Vorallokations- und Trace-Fastpath-Optimierungen bleiben erhalten.
