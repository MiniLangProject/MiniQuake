# Historical documentation archive

This directory preserves MiniQuake's package-by-package implementation,
testing, and acceptance records. These files are retained for provenance and
for reproducing older verification packages; they are not the current user or
build documentation.

The `changelog/` directory contains the former root-level `CHANGELOG_*.md`
snapshots. Some historical records preserve the language, terminology, and
paths used when they were produced. Consult the root `README.md` and
`docs/status/PORT_STATUS.md` for current English documentation.

The `releases/` directory contains the corresponding BP/OPT engineering,
testing, result, ledger, and audit documents that previously occupied the
documentation root. JSON evidence is kept beside the Markdown record that
describes it.

Historical patch files under `patches/` likewise retain their original paths
because they are immutable delivery evidence.
